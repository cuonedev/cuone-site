# 文章配图

本 Skill 用于本仓库文章的示意图、流程图和信息流小图。配图应服务文章论点；动笔前查看本目录 `references/demo.jpg` 和 `assets/images/posts/` 中相关已有 SVG，沿用系列视觉风格。

## 视觉方向

- 使用暖白纸张底色、深色手写感文字与轮廓线，以红、蓝、绿作为少量强调色；构图应适合手机阅读。
- 一张图只承担一个任务：解释关系、流程、对比或关键差异。图内使用短标签，完整说明留给正文。
- 根据关系含义选择线条几何形状：直接顺序或连接使用直线；只有回传、分支、绕行或跨层关系才使用曲线。不要为了模拟手绘效果而弯曲直线。
- 手绘感来自圆润的线端，以及略有不对称、由两笔构成的开放式箭头。箭头形状在 SVG 中只定义一次并复用。箭头尖端与连线终点必须共用同一坐标，不留可见缝隙；曲线箭头按终点方向旋转复用。
- 轮廓和连线保持清楚。避免噪点滤镜、素描叠层、随机抖动、装饰堆积和逐条临时修补箭头。

## SVG 与 PNG

- 流程图使用 SVG 制作，保证中文标签、布局和路径可编辑。结构保持简单规整：在 `<defs>` 中定义可复用图形，再依次组织背景、节点、标签和连线。
- 真正的直线使用 `L`；只有关系需要曲线时才使用 `Q` 或 `C`。同一篇文章的线宽、线端、箭头、配色和间距保持一致。
- 除非文章内容需要变化，否则保留现有图尺寸与信息。修改后检查标签、遮挡、箭头方向、线端连接和边距。
- `.svg` 源文件和对应 `.png` 发布文件始终同时保留。每次调整后，都从最终 SVG 重新导出 PNG。文章配图复制到 `cuone-site` 时，两种格式都要同步并确认副本一致。
- 以正常阅读尺寸检查导出的 PNG：文字可读、箭头与线条相连、流向正确、没有裁切，并与项目参考图保持一致。
